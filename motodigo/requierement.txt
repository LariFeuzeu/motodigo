| SQLAlchemy         | ORM pour interagir avec la base en Python    |
| alembic            | Gestion des migrations de la base de données |
| python-dotenv      | Pour charger les variables depuis `.env`     |
| passlib\[bcrypt]   | Hashage sécurisé des mots de passe           |
| python-jose        | Pour générer et vérifier les JWT             |
| pydantic           | Validation et sérialisation des données      |
